Questions
1. Which cloud provider offers the broadest range of services?

AWS provides the widest selection of cloud services among the three major providers. Its services cover areas such as computing, storage, databases, networking, security, analytics, artificial intelligence, software development, and many other technologies. Because of its extensive service portfolio, AWS can meet the needs of different organizations, including startups and large enterprises.

2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the most suitable option for organizations that already depend on Microsoft technologies. It integrates closely with services such as Windows Server, Microsoft 365, and Microsoft Entra ID. This integration makes it easier for organizations to manage their users, applications, security, and cloud resources within a Microsoft-based environment.

3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong platform for workloads involving Artificial Intelligence and Kubernetes. It provides various AI and machine learning services that organizations can use to develop and deploy intelligent applications. It also offers Google Kubernetes Engine (GKE), a managed Kubernetes service that helps users deploy, manage, and scale container-based applications.

4. Which cloud platform would you personally choose and why?

I would personally select AWS because it offers a wide range of services that can be used for many different projects. It provides solutions for computing, storage, databases, networking, security, application development, and other areas of cloud computing. Learning AWS would allow me to gain experience with various cloud technologies and could help prepare me for future IT projects and career opportunities.
