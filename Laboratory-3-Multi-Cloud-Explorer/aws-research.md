AWS Research
1. Brief Overview

Amazon Web Services (AWS) is a cloud computing service created by Amazon that offers many different technology resources through the internet. Its services cover areas such as computing, storage, databases, networking, security, analytics, software development, and other cloud solutions. AWS enables individuals, companies, and organizations to access technology resources whenever they need them without the need to buy and maintain physical servers. It uses a pay-as-you-go model, meaning users generally pay only for the resources and services they consume.

2. Global Infrastructure

AWS operates a large worldwide infrastructure that is designed to provide secure, reliable, and scalable cloud services. Its infrastructure is divided into Regions and Availability Zones (AZs). Each AWS Region contains several Availability Zones that function independently but are connected through fast and reliable networks. This arrangement helps applications continue operating even if an issue affects one location. AWS also has a global network backbone that supports faster data transfers, reduces latency, and improves the performance of applications and services around the world.

3. Cloud Management Console

The AWS Management Console is a web-based platform that allows users to access and manage AWS services. Users can create and configure cloud resources, monitor their services, adjust security settings, and check account and billing information through the console. It also includes search and navigation tools that help users locate AWS services more easily. In addition, AWS CloudShell allows users to execute command-line commands directly from a web browser.

4. Four Core Services
Amazon EC2

Amazon EC2 provides virtual servers that organizations can use to run applications and different workloads in the cloud.

Amazon S3

Amazon S3 is a scalable object storage service used to store files, documents, images, backups, and other types of data.

Amazon RDS

Amazon RDS is a managed relational database service that simplifies the process of creating, operating, and scaling databases.

Amazon CloudFront

Amazon CloudFront is a content delivery network (CDN) that helps deliver websites, applications, videos, and other digital content to users faster by reducing latency.

5. Three Advantages
Reduce Large Upfront Costs

Instead of investing a large amount of money in purchasing physical servers and constructing data centers, businesses can use AWS resources whenever necessary and pay according to their actual usage.

Benefit from Large-Scale Infrastructure

AWS provides services to many customers through its extensive cloud infrastructure. Because of its large scale, customers can access computing resources at a potentially lower variable cost than building and maintaining similar infrastructure on their own.

Easily Adjust Capacity

AWS allows organizations to increase or decrease their resources depending on their current demand. This reduces the need to predict future infrastructure requirements and helps avoid having too many or too few resources.

6. Typical Enterprise Use Cases

Businesses and large organizations can use AWS for various purposes, including:

Hosting websites and web-based applications
Storing and creating backups of business data and files
Operating and managing databases
Developing, testing, and deploying software
Creating scalable and highly available business applications
Processing and analyzing large amounts of business data
Implementing cloud-based security and monitoring systems
