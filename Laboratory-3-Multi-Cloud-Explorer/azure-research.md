Microsoft Azure Research
1. Brief Overview

Microsoft Azure is a cloud computing platform created by Microsoft that offers various services for developing, deploying, and managing applications and business solutions. It supports many areas of technology, including computing, storage, databases, networking, artificial intelligence, analytics, and security. Azure enables organizations to access cloud resources through the internet without having to manage all of their own physical hardware and infrastructure.

2. Global Infrastructure

Microsoft Azure has a worldwide infrastructure built to deliver secure, reliable, scalable, and high-performance cloud services. Azure operates through numerous regions and data centers located around the world. This global network allows organizations to deploy applications and store information closer to their customers, which can help improve performance and reduce network delays. Azure also emphasizes security, sustainability, and flexibility to support modern cloud applications and artificial intelligence workloads.

3. Cloud Management Console

The Azure Portal is a web-based management platform that allows users to create, configure, monitor, and control Azure resources in one centralized location. Through the portal, users can manage virtual machines, databases, storage, networks, applications, and other cloud services. Its user-friendly interface makes it easier for organizations to manage their resources efficiently across cloud and edge environments.

4. Four Core Services
Azure Virtual Machines (VMs)

Azure Virtual Machines provide virtual computing resources that can be used to run operating systems, applications, and various workloads in the cloud.

Azure Blob Storage

Azure Blob Storage is a scalable storage service designed for handling large amounts of unstructured data, including documents, images, videos, backups, and application files.

Azure SQL Database

Azure SQL Database is a fully managed relational database service based on Microsoft SQL Server technology. It is designed to provide reliable, scalable, and high-performance database capabilities.

Azure Virtual Network Manager

Azure Virtual Network Manager helps organizations create, organize, and manage virtual networks across multiple Azure regions and subscriptions through a centralized management system.

5. Three Advantages
Azure Free Account

Azure provides new users with a free account that allows them to try selected Azure services and resources for a specific period or within certain usage limits.

Azure for Students

Qualified students can access Azure benefits, including monthly free service allowances and Azure credits. These resources allow students to practice and learn about cloud computing technologies.

Azure for Nonprofits

Eligible nonprofit organizations can receive Azure grants and discounts. These benefits can help nonprofits lower their cloud expenses while supporting their digital transformation efforts.

6. Typical Enterprise Use Cases

Microsoft Azure is commonly used by businesses and organizations for:

Hosting websites, mobile apps, and business applications
Storing and backing up important business information
Operating and managing cloud-based databases
Moving existing IT infrastructure to the cloud
Developing Artificial Intelligence and Machine Learning solutions
Supporting business continuity and disaster recovery
Creating scalable enterprise applications
Managing cloud networking and security
